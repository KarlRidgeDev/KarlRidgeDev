# Kali Linux Penetration Testing Lab

## Objective
Practise identifying and investigating vulnerabilities in an authorised testing environment.

## Tools Used
Kali Linux, Nmap, Metasploit Framework and Metasploitable.

## What I Did
- Set up a penetration testing environment.
- Performed network scans to identify open ports and running services.
- Identified the vulnerable vsftpd 2.3.4 FTP service.
- Used Metasploit to demonstrate exploitation in a controlled lab.
- Investigated network security on my own Windows laptop.

## What I Learned
I gained practical experience in network reconnaissance, vulnerability identification and ethical hacking. I also learned why outdated services present security risks and why systems should be regularly patched and secured.

## Ethical Statement
All testing was performed on systems I own or was authorised to test.
